# 第三方来源更新模式（已确认）

来源可配置“自动更新”或“仅手动更新”，默认自动，旧记录缺字段时同样按自动处理。只按模式控制请求，不对任何上游 HTTP 状态码增加特殊逻辑。

自动沿用当前按需两小时缓存策略；仅手动在系统订阅访问/下载生成时只复用已有来源缓存，包括过期或配置失效后保留的缓存，并使用现有 stale 标志。无可用缓存时明确提示先手动更新，不向上游请求。HEAD/预览/来源下载规则保持。

两种模式均可点击单条“更新”和“全部更新”，仍强制获取新缓存，失败保留旧数据/成功时间，记录实际更新。切换模式不使缓存失效、不改变最近成功时间；切换前已发起的更新可正常完成，之后不再发起自动请求。

新增/编辑使用“仅手动更新”复选框，默认不勾选（自动更新），勾选即仅手动更新；来源名称下展示更新模式。不新增数据版本或重置数据，PATCH 未提供模式时保留原值。请求期间切换模式时，配置指纹及来源读取校验纳入模式，禁止新自动任务绕过手动配置。

# 三类模板设计（已确认）

基础模板单选，维护基础配置及 DNS 中除 nameserver 外的配置；nameserver 独立维护名称和单个完整地址，多选；规则模板单选，组装时仅取 proxies、proxy-groups、rules。仅规则模板做业务结构校验，基础模板只校验 YAML 语法，nameserver 不限制 DNS 协议。名称必填、长度限制、引用存在和授权等通用校验保留。

系统订阅可勾选“使用订阅源 nameserver”，手动选择仍可用且作为备用。开启时按来源顺序合并所有来源缓存正文的 dns.nameserver，字符串地址去空白去重；只要来源有可用项，就不补入手动地址；全部来源无可用项时使用手动备用。关闭时仅用手动地址。最终没有地址时明确报错。含 # 的地址原样保留，不检查/自动改写其分组引用。

顺序：基础模板 → 写入选出的 dns.nameserver → 规则模板三个字段 → 原有节点聚合与国家分组。基础中即使填写了规则或 nameserver，也不会取得对应字段所有权，不在保存时额外拒绝。模板编辑下次访问即生效，不拉取有效来源缓存。被引用记录禁止删除。

三类独立导航和 CRUD；基础/规则支持 YAML 文本及文件读取，保留宽编辑弹窗。订阅显示基础、规则、DNS 模式和手动/备用配置。nameserver 按地址去重，按用户选择记录的持久化顺序组装。

不迁移、不自动拆分旧持久数据，不删除原数据。数据版本升为 3，拒绝旧格式并提示改用新 DATA_DIR 重新维护。新空目录从 prds/template.yaml 提取三类初始默认项；原 /sub?url 兼容转换入口继续使用该完整文件。正文和套餐缓存 2 小时及套餐透传行为保持。当前 master 工作区实施，不自动提交。

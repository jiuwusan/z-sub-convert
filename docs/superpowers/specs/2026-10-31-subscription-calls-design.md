# 系统订阅调用记录（已确认）

仅公开 `/sub?key=...` 的 GET/HEAD 请求归属到匹配的系统订阅；后台下载不计入，旧 `/sub?url` 不计入，无法归属的错误 key 不记入任何订阅。记录成功和失败，字段为调用时间、方法、来源 IP、User-Agent、状态码、处理耗时和错误原因。不存 key、完整 URL 或正文。来源 IP 使用连接地址，不默认信任代理头。

每个订阅展示最近 72 小时记录，不再设 200 条上限。日志以按订阅/UTC 日期分片的 JSONL 保存于 DATA_DIR/call-records，追加写入，按订阅串行化；配置与缓存不参与日志写入。查询严格过滤 72 小时，启动及每 15 分钟清理磁盘过期记录。删除订阅同步删除记录，排队中的旧调用不能重新创建已删除订阅日志。日志写失败不改变订阅响应。

管理 API 需要登录，分页每页 50 条，按调用时间倒序。系统订阅列表增加“调用记录”入口，弹窗显示所选订阅名称、最近三天说明、刷新和翻页；切换页面/注销后丢弃过期请求结果。长 UA/错误消息可换行，移动端保留弹窗内横向滚动。监听响应完成/关闭后异步追加记录，不等待日志磁盘写入；耗时为服务端收到请求至响应完成/连接关闭的时间，响应完成前断开记 499，正常响应记实际状态码。

不改变 schema v3，不迁移数据；现有空日志显示暂无记录。当前分支实现，不自动提交。

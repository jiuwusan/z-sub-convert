# 系统订阅移除故障转移组

系统订阅新增/编辑增加“移除‘故障转移’组”复选框，默认不勾选。保存 removeFailover 布尔值，旧记录缺字段为 false，PATCH 省略字段保留已有值。仅影响当前系统订阅生成结果，不修改共享规则模板或来源缓存，不改变缓存有效期、订阅 key、套餐及日志规则。

选中时在现有完整转换之后删除名称精确匹配“🔰 故障转移”的顶层组；各国家/协议生成的 fallback 组保留。其他组对该组的 proxies 引用展开为它原有的成员，并去重，避免留下空引用或改指节点选择产生自循环。规则/子规则的目标引用、DNS 地址片段中的组引用、节点及 provider override 的 dialer-proxy 引用改指“🚀 节点选择”，不修改无关名称、凭据或地址。

规则模板仍按原规则要求两个必要分组；移除是单订阅输出选项。公开订阅及后台系统下载采用相同行为，模板下载和旧 /sub?url 保持原样。配置指纹包含该选项，请求期间切换后按最新值生成。

# 订阅国家筛选

创建、编辑系统订阅时增加“自定义国家”复选框，默认不勾选，全部节点加入。勾选后展示所选来源实际包含的国家标签（国旗、名称、节点数），允许多选，至少选择一项。

复用 country.js 名称识别与排序，无法识别的归为“其他”。国家列表只解析来源节点，不通过节点 IP 进行地理查询。

方案比较：仅页面过滤无法约束后续公开订阅更新；保存国家白名单并在后端转换前过滤可持续生效，因此建议后者。国家排序、协议排序不在本次范围。

每份订阅独立持久化 customCountries（默认 false）、countryCodes（默认 []）。关闭开关时忽略名单但允许保留选择。服务端验证开关类型、代码合法性、启用时非空；编辑省略字段保留旧值，历史记录默认全部。过滤作用于上游节点，生成节点、分组及主组引用保持一致，不改共享缓存和模板自有节点。

国家候选通过需登录的接口按选定 sourceIds 读取来源：复用现有 sourceContent 缓存/更新规则，手动模式不自动抓取；来源错误可见，不能把部分成功伪装成完整国家列表。只返回国家代码、名称、旗帜、数量，不返回凭据和节点正文。请求受现有认证保护，写请求遵循现有 CSRF 校验。

前端切换来源时刷新候选，忽略过期响应和已关闭表单的响应；保留已选国家，即使当前来源暂时无该国家，显示暂无节点，避免静默改动白名单。默认关闭时无需额外解析请求。启用且无匹配节点时给出明确错误，不自动放开为全量。

验证覆盖默认兼容、识别/其他、多来源聚合、保存和重启、关闭恢复全量、过滤后分组引用、无匹配节点、非法输入、缓存复用和更新期间配置变更，以及页面标签交互与过期响应保护。仅本地假源验证，不自动提交推送。

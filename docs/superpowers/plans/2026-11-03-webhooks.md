# Webhook 套餐提醒 Implementation Plan

**Goal:** 配置钉钉和飞书，提醒 3 天内到期和剩余流量小于 30GB。
**Architecture:** 独立 Notifications 模块负责验证、平台消息、缓存检查、持久化去重和定时器；后台 API 与配置页连接该模块。
**Tech Stack:** Node.js、原生 JS/CSS、node:test，无新增依赖。
**Spec:** docs/superpowers/specs/2026-11-03-webhooks-design.md

## Global Constraints

当前分支实现；兼容 v3；定时检查不主动拉取；到期成功按北京时间每天去重；流量预警按每次成功更新去重；失败不影响订阅。

## Review Focus

# 订阅源 nameserver 来源多选

## 设计
系统订阅勾选“使用订阅源 nameserver”后显示关联来源的名称标签多选。字段 `nameserverSourceIds` 保存来源 ID 数组，空数组/旧字段缺失表示聚合全部关联来源；非空仅提取指定来源的 dns.nameserver。顺序遵循订阅关联源顺序，地址仍按既有逻辑去重。指定来源均无地址时使用手动备用；不回退到未指定来源。

DNS 来源只能是当前订阅的关联来源，非法类型、超过 50 项或显式传入非关联 ID 均拒绝。更新省略字段保留原选择，关联来源减少时过滤失效选择。关闭来源 DNS 模式时保留选择，手动 DNS 生效。来源节点聚合、套餐、缓存和更新逻辑不变；不增加上游请求。字段纳入配置指纹，持久化重启、并发编辑和下载均使用最新配置。

# 系统订阅来源上移/下移

## 设计
在系统订阅新增/编辑的第三方来源列表增加已选来源的“上移/下移”按钮，独立于复选框标签，按钮 type=button。已选来源集中在顶部，新勾选追加到队尾；上移/下移只交换相邻已选来源，首尾方向按钮禁用。取消勾选后移出已选队列；重新勾选追加到末尾。

直接调整表单来源行的 DOM 顺序，保存仍通过 FormData.getAll('sourceIds')，后端已有顺序保存、去重及生成逻辑复用。nameserver 来源标签随顺序联动、保留已选 DNS 来源。取消弹窗不保存，重新编辑回显已保存顺序。按钮独立布局，长名称/URL 可换行，手机无横向溢出；键盘可操作、移动后保留焦点。

## 验证结果
- 修改前浏览器确认没有移动按钮，修改后新增按 C/A/B 勾选可上移下移至 B/C/A，保存回显一致，生成组按国家交错使用 B/C/A 顺序。
- 取消重选追加末尾，编辑取消后恢复已保存顺序；DNS 来源标签顺序联动且保留 B 的选择。来源更新记录各一次，排序未重新拉缓存。
- 零项时隐藏按钮，单项时两个方向均禁用；首尾方向禁用，操作不提交表单或改变勾选。
- 手机 390px 文档无溢出，弹窗宽 356px；长名称换行且复选框保持宽度，无控制台错误。
- 复现列表 DOM 重排导致取消/勾选后失焦，再保存并恢复可用焦点；浏览器验证取消、勾选、移动后焦点均保留。

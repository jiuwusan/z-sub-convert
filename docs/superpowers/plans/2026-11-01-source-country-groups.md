# 来源国家分组与排序

## 设计
系统订阅按来源、协议、国家分别生成 fallback 组，不再跨来源合并。同源同国家编号跨协议递增，格式为 `🇺🇸 A SS 美国`（组）、`🇺🇸 A 美国 01`（节点）；单源也带来源名称。顺序为国家优先级（美国、日本、新加坡等）、订阅选择的来源顺序、现有协议优先级。追加到节点选择、故障转移及最终组数组的顺序一致，模板原有成员顺序不变。顶层节点顺序仍为来源聚合原序。

沿用偶数节点前置、移除故障转移和 DNS 来源选择。生成时读取当前来源名称，改名不更新缓存。来源名称纳入配置指纹；重名来源使用消歧后缀，生成名称与模板既有名称碰撞时也消歧，保证引用有效。旧 `/sub?url` 无后台来源名称，继续使用旧命名/协议优先排序；transformConfig 通过可选 sourceNames 参数接入元数据，不变更旧调用。

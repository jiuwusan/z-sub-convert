# 国家分组偶数节点前置

## 设计
系统订阅新增/编辑提供“偶数节点前置”复选框，默认关闭，旧记录缺字段也关闭。字段 `evenNodesFirst` 为布尔值，更新时省略则保留现值，拒绝其他类型。

取消原先固定交换前两项：关闭时分组内保留聚合源及源内顺序；开启时按生成编号的奇偶稳定分区，偶数在前、奇数在后。编号仍按同一国家跨协议连续递增，必须判断编号而非每组位置。例如 02、03、04 排成 02、04、03。节点名称及顶层 proxies 顺序、组排序均不受此选项影响。

按订阅保存并纳入配置指纹；公开订阅及后台下载共用，不更改来源缓存或共享模板。切换无需重新拉取有效缓存，请求期间变更使用最新配置。

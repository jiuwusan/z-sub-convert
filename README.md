# Clash.Meta 订阅转换服务

一个面向 Clash.Meta/Mihomo 的轻量 Node.js 订阅转换服务。它可合并多个 Clash YAML 订阅，按照“协议优先、国家/地区其次”生成 fallback 分组，重命名节点，并注入 `prds/template.yaml`。

## 订阅管理后台

启动后打开 `http://127.0.0.1:25500/`（也支持 `/admin`）。首次使用直接设置用户名和密码，无需 key；密码须为 8–128 个字符。后续通过用户名、密码登录。账号密码以 scrypt 哈希存储，登录会话有效期为 12 小时，服务重启后重新登录。

后台使用原生 hash 路由，无需额外前端依赖或服务端路径重写。系统订阅、第三方订阅源和模板分别对应 `#/subscriptions`、`#/sources`、`#/templates`；支持直接打开、刷新后保留当前页、浏览器前进/后退及新标签页打开。登录、首次初始化和重置账号分别使用 `#/login`、`#/setup`、`#/reset`。未登录访问管理页面时跳转登录，登录后返回原页面；跳转目标仅接受上述管理页。

1. **第三方订阅源**：维护名称、User-Agent、订阅链接。新增 User-Agent 默认为 `clash-verge/v2.4.5`，后台列表隐藏链接路径、令牌参数及其值。编辑时可查看完整链接。每个来源独立缓存原始节点数据，列表展示缓存状态、最近成功时间和最近更新结果，提供单条“更新”和“全部更新”。
2. **订阅模板**：独立维护名称和 YAML 内容，支持 textarea 编辑或读取本地文件。保存时校验 `proxies`、`proxy-groups`，以及“🚀 节点选择”“🔰 故障转移”分组的 `proxies` 数组。首次初始化数据目录时从 `TEMPLATE_PATH` 创建“默认模板”，后续不重复创建或覆盖。
3. **系统订阅**：输入名称、多选第三方来源、选择模板。列表提供编辑、复制订阅链接和删除。访问时读取所选来源缓存并应用当前模板生成结果；需要更新第三方数据时到来源列表更新。被引用的来源、模板不能删除；删除系统订阅会撤销其链接。

复制出的链接格式为 `/sub?key=xxx`，无需后台登录即可供客户端使用。每条订阅有独立随机 key，修改配置、更新、重启或重置账号均不改变链接。

来源列表提供“预览”，登录后可查看第三方返回的完整订阅原文（包括 DNS、分组、规则、其他配置和注释，未套用系统订阅模板），并复制内容。缓存保留原文格式和换行，不通过节点重新拼装。预览展示节点数量、缓存状态和最近成功更新时间；无缓存时提示先“更新”，过期或配置变更后保留的完整旧缓存仍可查看。旧版本仅保存节点的缓存仍可用于系统订阅转换，预览会提示更新一次以取得完整结果。打开预览不拉取第三方订阅。“刷新”只重新读取列表，“更新 / 全部更新”才主动更新来源缓存。

来源列表、来源预览弹窗和系统订阅列表均提供“下载”。文件名为 `名称-下载时Unix毫秒时间戳.yaml`，支持中文名称；不适合文件名的字符自动替换，超长名称适当截短。来源下载读取完整缓存原文，不触发上游请求，无缓存或只有旧版节点缓存时提示先更新；系统订阅下载生成所选本地模板的完整配置，缓存缺失或过期时按既有规则更新来源。直接访问 `/sub?key=...` 也使用系统订阅名称作为下载文件名。后台下载接口需要登录。

### 缓存规则

- 缓存以**第三方订阅源**为单位保存完整原始订阅文本，多个系统订阅复用；生成系统订阅时从原文提取节点，仍使用所选本地模板，不缓存转换后的系统订阅成品。
- 保存配置不拉取。访问系统订阅时，只有无缓存、配置失效或超过 **2 小时**的来源才拉取，其他来源直接复用缓存。有效期从该来源最近成功时间计算，没有定时拉取。
- 来源列表的单条“更新”和“全部更新”强制更新来源；全部更新包括尚未被系统订阅使用的来源，逐条报告结果。更新成功后所有关联订阅在下次访问时使用新数据。
- 每个来源独立更新。某个来源失败时保留它的旧缓存和最近成功时间，不影响其他来源更新。系统订阅可使用失败来源的旧数据与其他来源的新数据组合；任一所选来源完全无缓存且拉取失败时，返回错误，不输出缺少来源的部分结果。
- 修改来源 URL/User-Agent 只使该来源缓存失效；修改名称不影响缓存。修改模板或系统订阅关联后，下次访问按当前配置生成结果，仍有效的来源不重新拉取。
- 同一来源同一配置的并发拉取跨系统订阅合并。编辑前启动的旧更新不会覆盖编辑后的来源缓存。
- 对 `/sub?key=...` 的 HEAD 请求检查链接并输出已有缓存的聚合套餐信息，不触发拉取。

### 套餐信息

通过一次 GET 同时获取来源的完整订阅正文和 `subscription-userinfo` 响应头，正文与套餐共享同一份缓存和 2 小时有效期，不额外发送套餐探查请求。来源列表仅展示总流量、剩余流量、到期时间，共用现有最近成功时间和更新结果。上游未提供有效套餐字段时显示“未提供”，缺失字段显示“—”；剩余流量需要总量、上传、下载三个字段齐全才能计算，用尽后显示 0。

系统订阅按来源 ID 去重，上传量、下载量、总流量求和，到期时间取最晚值。部分来源无套餐信息时，仅聚合有数据的来源，后台显示“套餐信息覆盖 N/M 个来源”；单个字段缺失时不补零，仅计算已提供的值。所有来源均无数据时不输出套餐头。`total=0` 按无限流量处理，`expire=0` 按长期有效处理；聚合中出现对应特殊值时，聚合结果保留 0。最晚到期时间不代表所有来源均可用至该日期，共享账户的不同来源也可能重复统计额度。

公开系统订阅 `/sub?key=...` 及后台系统订阅下载输出聚合套餐头；第三方来源下载输出其自身缓存的套餐头。HEAD 仅读取已有元数据，不拉取上游。旧缓存没有套餐信息也可继续使用，下一次成功更新后补齐。更新失败保留旧正文和旧套餐；成功返回有效正文但套餐头缺失/无效时，清除旧套餐信息。其他上游响应头不透传，文件名仍使用本系统的“名称-时间戳”。旧 `/sub?url=...` 兼容转换入口保持原有行为。

旧版数据首次启动时自动升级：账号、来源、模板、系统订阅及订阅 key 保留。旧版转换成品缓存无法还原为各来源的原始数据，因此不再复用；来源缓存由首次访问或来源列表手动更新建立。

### 第三方订阅请求排查

更新结果中的网络错误会附带经过筛选的底层错误码，帮助区分容器环境问题；不会显示完整 URL、token、节点内容或证书错误详情。

| 错误码 | 排查方向 |
| --- | --- |
| `ENOTFOUND` / `EAI_AGAIN` | 容器内的域名解析、DNS 可用性 |
| `ENETUNREACH` / `EHOSTUNREACH` / `ETIMEDOUT` / `UND_ERR_CONNECT_TIMEOUT` | 容器出口路由、防火墙、上游连接可达性 |
| `ECONNREFUSED` / `ECONNRESET` / `UND_ERR_SOCKET` | 连接被拒绝、连接重置或传输中断 |
| `UNABLE_TO_VERIFY_LEAF_SIGNATURE` / `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` | 上游证书链与容器信任根 |
| `CERT_HAS_EXPIRED` / `CERT_NOT_YET_VALID` | 证书有效期、部署机器系统时间 |
| `ERR_TLS_CERT_ALTNAME_INVALID` | 访问域名与返回证书是否匹配 |

本机浏览器或本地请求成功，不代表容器的 DNS、出口网络和证书环境相同。需要在部署机器的容器内复测，保留 TLS 证书校验。

### 重置用户名 / 密码

容器每次启动会输出随机账号重置 key；进程异常重启时也会轮换。查看日志：

```bash
docker logs -f clash-sub-convert
```

找到最新的 `Account reset key (rotates on startup): ...`，在登录页点击“忘记账号或密码？”，填写该 key、新用户名和新密码。重置后所有已登录会话失效；旧启动 key 无效，订阅链接不受影响。本地运行可直接从启动终端查看 key。

### 数据持久化

`DATA_DIR` 存放账号、来源、模板、系统订阅和缓存。Compose 默认使用 `sub-convert-data` 命名卷，容器重建后保留数据。备份时停止服务并备份整个数据目录；不要执行 `docker compose down -v`，该命令会删除数据卷。自定义绑定目录需允许容器内 `node` 用户（UID 1000）写入。

当前存储面向单进程部署，同一数据目录不能由多个服务实例同时写入。首次初始化期间请自行控制后台访问；公网部署建议通过 HTTPS 反向代理访问。

## 转换规则

- 分组名：`国旗 大写协议 国家名称`，例如 `🇸🇬 SS 新加坡`、`🇯🇵 HYSTERIA2 日本`。
- 节点名：`国旗 国家名称 编号`，例如 `🇸🇬 新加坡 01`。
- 同一国家/地区跨协议连续编号，避免 Clash 配置中出现重复节点名。
- 每个生成的协议/国家分组包含至少 2 个子节点时，交换第 1、2 个节点的位置，其余节点顺序和编号保持不变。
- 国家识别顺序：国旗、中文名、英文名、独立常见缩写；无法识别时使用 `🏳️ 其他`。
- 协议优先级：`ss → ssr → hysteria2 → trojan → vmess → vless → tuic → hysteria → wireguard → 其他`。
- 国家优先级：`美国 → 日本 → 新加坡 → 其他已识别国家 → 香港 → 台湾 → 其他`。其他已识别国家按中文名称排序。

## 本地运行

需要 Node.js 22 或更高版本：

```bash
npm ci
npm start
```

服务默认监听 `0.0.0.0:25500`。

## API

健康与版本信息：

```text
GET http://127.0.0.1:25500/version
```

转换单个订阅：

```text
GET http://127.0.0.1:25500/sub?url=<URL编码后的订阅地址>
```

合并多个订阅时，先用 `|` 连接地址，再对整个参数值进行 URL 编码：

```text
GET http://127.0.0.1:25500/sub?url=<URL编码后的订阅1|订阅2>
```

兼容 subconverter 风格的调用链接，但 `target` 和其他额外查询参数都会被忽略；输出始终为 Clash.Meta/Mihomo YAML。

成功响应的下载文件名包含当前 Unix 毫秒时间戳，例如 `config-clash-meta-1789353600123.yaml`。

```text
GET /sub?target=anything&url=<已编码地址>&emoji=false
```

抓取上游订阅时固定发送 `User-Agent: clash-verge/v2.4.5`。

## Docker Compose 部署

```bash
docker compose pull
docker compose up -d
```

从当前源码构建并运行可使用 `docker compose up -d --build`。

镜像基于 `node:22-alpine`，通过 `pm2-runtime` 运行。PM2 的 `max_memory_restart` 设置为 `256M`，进程内存达到阈值后会自动重启。

模板已复制到镜像内的 `/app/prds/template.yaml`，因此默认 Compose 配置不需要挂载模板即可正常使用。

如需在不重建镜像的情况下覆盖模板，可在 `docker-compose.yml` 的服务下添加只读挂载：

```yaml
    volumes:
      - ./prds/template.yaml:/app/prds/template.yaml:ro
```

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | ---: | --- |
| `HOST` | `0.0.0.0` | 服务监听地址 |
| `PORT` | `25500` | Node 服务监听端口；Compose 中宿主机端口也可通过同名变量调整 |
| `UPSTREAM_TIMEOUT_MS` | `15000` | 单个上游请求超时（毫秒） |
| `MAX_UPSTREAM_BYTES` | `10485760` | 单个上游响应最大字节数（默认 10 MiB） |
| `TEMPLATE_PATH` | `prds/template.yaml` | 模板文件路径 |
| `DATA_DIR` | `data`（容器内 `/app/data`） | 后台配置、账号和订阅缓存的持久化目录 |
